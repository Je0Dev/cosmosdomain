# `com.papel.imdb_clone` — Application Root Package

Main package for the IMDb Clone application. Contains all source code organized by architectural layer.

Packages:
- `config/` — Application configuration
- `controllers/` — JavaFX MVC controllers (UI logic)
- `data/` — Data facade / central data manager
- `enums/` — Enumeration types
- `exceptions/` — Custom exception classes
- `gui/` — JavaFX Application class (entry point)
- `model/` — Domain models
- `repository/` — Data access layer
- `service/` — Business logic layer
- `tools/` — Utility tools
- `util/` — General utility classes

Files:
- `StartApplication.java` — Application entry point (`main()` method)
