# `service/` — Business Logic Layer

Contains all business logic services organized by domain. Follows the Service Locator pattern for dependency management.

Sub-packages:
- `content/` — Content services (movies, series)
- `data/` — Data loading and file parsing
- `navigation/` — Screen navigation
- `people/` — People and user services
- `rating/` — Rating services
- `search/` — Search and ServiceLocator
- `validation/` — Authentication and validation
