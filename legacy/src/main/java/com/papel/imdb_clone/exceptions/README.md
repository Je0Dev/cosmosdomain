# `exceptions/` — Custom Exceptions

Contains application-specific exception classes for structured error handling.

Files:
- `AuthErrorType.java` — Authentication error type enum
- `AuthException.java` — Authentication-related exceptions
- `DataPersistenceException.java` — Data save/load failures
- `DuplicateEntryException.java` — Duplicate data entries
- `EntityNotFoundException.java` — Entity not found
- `FileParsingException.java` — File parsing errors
- `InvalidEntityException.java` — Invalid entity state
- `InvalidInputException.java` — Invalid user input
- `UserAlreadyExistsException.java` — Duplicate user registration
- `ValidationException.java` — General validation errors
