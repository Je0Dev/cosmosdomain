# `repository/impl/` — Repository Implementations

In-memory implementations of the repository interfaces using collections.

Files:
- `InMemoryMovieRepository.java` — In-memory movie storage
- `InMemorySeriesRepository.java` — In-memory series storage
- `InMemoryCelebritiesRepository.java` — In-memory celebrity storage
- `InMemoryUserRepository.java` — In-memory user storage with serialization
