# `repository/` — Repository Interfaces

Defines the data access contracts (interfaces) for the repository layer.

Sub-packages:
- `impl/` — In-memory implementations of the repository interfaces

Files:
- `MovieRepository.java` — Movie data access interface
- `SeriesRepository.java` — Series data access interface
- `CelebritiesRepository.java` — Celebrities data access interface
- `UserRepository.java` — User data access interface
