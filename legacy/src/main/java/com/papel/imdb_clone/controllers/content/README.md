# `controllers/content/` — Content Controllers (Movies & Series)

Contains controllers and helper classes for managing movies and TV series.

Files:
- `MoviesController.java` — Movie listing, search, sort, CRUD
- `MoviesDialogHelper.java` — Dialog creation for movies
- `MoviesLogicHelper.java` — Movie filtering, sorting, table setup
- `SeriesController.java` — Series listing, seasons, episodes, CRUD
- `SeriesDialogHelper.java` — Dialog creation for series/seasons/episodes
- `SeriesLogicHelper.java` — Series filtering, sorting, table setup
- `ContentDetailsController.java` — Detailed content view
- `EditContentController.java` — Content editing form
