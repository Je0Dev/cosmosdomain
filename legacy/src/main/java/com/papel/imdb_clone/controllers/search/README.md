# `controllers/search/` — Search Controllers

Contains controllers and helpers for the search functionality.

Files:
- `AdvancedSearchController.java` — Advanced multi-criteria search
- `BaseSearchController.java` — Abstract base search controller
- `ResultsTableController.java` — Search results display
- `SearchCriteria.java` — Search criteria model
- `SearchFormController.java` — Search form UI
- `SearchLogicHelper.java` — Search filtering and sorting logic
