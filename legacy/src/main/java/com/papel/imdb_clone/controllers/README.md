# `controllers/` — MVC Controllers (UI Logic)

Contains all JavaFX controllers that handle user interaction and UI logic. Organized into sub-packages by feature domain.

Sub-packages:
- `authentication/` — Login and registration
- `content/` — Movies and TV series views
- `coordinator/` — UI navigation and screen coordination
- `people/` — Celebrities (actors/directors) views
- `search/` — Search functionality

Files:
- `BaseController.java` — Abstract base controller with shared functionality
- `MainController.java` — Main application window controller
